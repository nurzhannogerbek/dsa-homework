# ДЗ 2. Функции и словари на настоящих данных

Решение в [hw02.ipynb](hw02.ipynb). Сделаны все задачи: База, Стандарт и Челлендж. Предсказания для блока «Чтение кода» тоже написал.

Пара моментов по ходу решения:

- города пришлось чистить через словарь, в данных куча вариаций: `almaty`, `АЛМАТЫ`, ` Astana ` с пробелом в конце и т.д.
- суммы тоже были с сюрпризами, в некоторых строках пробелы вместо точек (`6 470`), поэтому `to_num` сначала убирает пробелы, а потом делает `float`
- в задаче 7 на первое место вырвался клиент `TEST` с выручкой почти 30 млн тенге. Понятно, что это тестовая запись, которая ломает всю статистику по топам
- для поиска дублей в 9-й задаче превращал строки в `tuple(r.values())` и кидал в `set`. Дублей оказалось реально много, почти во всех категориях
- в челлендже, когда пересчитывал чистую выручку, стало видно, что первый расчёт был вообще неверным из-за тестового клиента

Если коротко по цифрам: изначальный расчёт показывал, что октябрь рухнул по сравнению с сентябрём. Но после удаления всех дублей и заказов клиента `TEST` выяснилось, что падение не такое катастрофическое (а может, его и вовсе нет, точные цифры в ноутбуке).

Главный вывод для менеджера: если смотреть на «сырые» данные без очистки, можно нарисовать неверную картину и зря паниковать. Дубли и тестовые записи сильно искажают реальную аналитику.
